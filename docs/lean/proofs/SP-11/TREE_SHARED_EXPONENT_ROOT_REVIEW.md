# Independent tree, shared-exponent and predecessor-structure review

Reviewer: `/root`, OpenAI Codex AI agent, 17 October 2026. APPROVE for the
listed support gates. I implemented none of these modules. This is not a proof
of the remaining unique-coefficient claim or of the complete SP-11 target.

GardenColors sorts every actual injective conduit tuple using its finite image
and a genuine permutation. The coefficient of the concrete universal form is
therefore its alternating sign times the original shared vertex/subset
variable. A noninjective tuple has coefficient zero. The chosen subset and
permutation are data justified by proved existence; they do not assume a
favorable graph representation. Empty arity and repeated colors are covered.

GardenTree uses an ordered finite rose tree and a color at every actual node
occurrence. Forms are indexed by original labels, so duplicate labels reuse
the same form. The finite multilinear expansion retains every coloring and
its scalar weight. LSSGarden constructs the actual earlier-nonneighbor tree
by well-founded recursion and proves evaluation equals the original
uniformLSS, so it does not substitute an unrelated diagram model.

DoubleRootGarden shares one cap color between the two roots. It proves the
bilinear pairing is the full sum over those paired colorings. Its explicit
occurrence index is root plus all dependent child occurrences, and the double
index is the disjoint sum of both actual node sets. The product and exponent
sum each count every node exactly once while naming polynomial variables only
by original vertex and coordinate subset. Product-of-monomials algebra gives
the literal actual polynomialGram signed-monomial expansion. Invalid local
colors have sign zero and may share an exponent; no injectivity or uniqueness
of the monomial terms is silently inferred.

PriorListStructure derives strict sibling ordering from the actual sorted
predecessor list, identifies smaller-value count with zero-based slot, and
combines it with the exact OrderedGreedy inequality. The augmented list inserts
an earlier root; adjacency explicitly excludes its duplication with a
nonneighbor. Every augmented label is below the later root, and insertion can
only increase the count of smaller ordinary children. The arity-at-most-slot
bound is consequently valid for ordinary and augmented children without
assuming distinct occurrences. All arithmetic endpoint bounds are natural
numbers and include empty lists. The later root restriction is explicit.
