The explicit SVD opcode reads row/column dimensions and four base addresses from natural registers. `readMatrix` reads the entire old input with row-major addresses. `ValidSVD` requires full square U and V with orthonormal columns, every singular value nonnegative, every pair's nonincreasing order, and exact reconstruction using all min(rows,columns) values. The relation permits every such response and includes no selected choice function.

`DisjointBlocks` expresses exact half-open block disjointness, with either empty block handled explicitly. Overlapping output blocks fail. Input overlap is permitted because reconstruction and reads use the old store. `writeSVD` writes all U, sigma and V cells in their disjoint row-major blocks and retains every other old cell. A successful SVD step changes only the instruction label and these cells. `ordinaryStep` has a defensive SVD failure case, but the structural `Step` relation never calls that case: it handles every SVD opcode by the explicit relation first.

`charge` is determined solely by the actual current program instruction and state: scalar instructions and successful halt cost one, SVD costs `(rows+columns+1)^3`, and already terminal states cost zero. `Step` forces the recorded trace cost to equal this value. `LegalTrace` starts at the actual initialized state and follows Step at every natural time, with successful/failed states absorbing. Thus supplied trace cost data cannot manufacture a bound. A failed trajectory has no successful output, and every running step has positive cost.

Input natural register zero is the order; all other registers are zero. The standard positional identity makes Offset a bijection onto the N dense offsets and Decode its inverse there. The mode lower bounds ensure every radix and suffix product is positive. No optimizer, unfolding rank, error or basis is present in the input.

The complete N-entry result is already stored; reading the output adds at most a polynomial N serialization cost if charged separately. `Size` is the exact approved natural dense size plus order plus numerical rank sum plus one.
