# TR-06 exact mathematical and numerical target

`ORIGINAL.md` retains the complete permanent canonical README byte for byte. This is a pre-implementation specification, not a proof of integrability.

Fix **every** tensor order `d≥3`, all real factor dimensions `n_j≥2`, and every rank `r≥3`, subject to the canonical generic **complex** identifiability assumption: outside a proper complex algebraic exceptional set, a complex tensor of rank `r` in that format has a unique unordered collection of `r` rank-one summands. Do not substitute generic real identifiability, one convenient format, or a uniformity assumption across formats. The source context defines `r≥2`, but the target asks for `r≥3`; rank two is already known.

Let `M_r` be the smooth identifiable locus of **real rank-r tensors** in the ambient real tensor product. It has the Euclidean Riemannian volume induced from the ambient Frobenius inner product, not a parameter-space volume or the law obtained by independently Gaussian-sampling rank-one summands. Give it probability measure `μ(dA)=Z^{-1} exp(−‖A‖_F²/2) dV(A)` with the actual finite positive normalizer `Z=∫_{M_r} exp(−‖A‖_F²/2)dV(A)`. If an implementation extends integrands across exceptional sets, those extensions must only affect a `μ`-null set.

The addition map `Φ(a₁,…,a_r)=∑ᵢaᵢ` has rank-one summands as inputs. On a local identifiable branch, `Ψ` is its local inverse to the tuple of summands; the unordered permutation ambiguity does not alter the product Euclidean operator norm. Each summand is **individually** normalized by `p(a)=a/‖a‖_F`, with product map `p^{×r}`. At `A`, define `κ_ang(A)=‖D(p^{×r}∘Ψ)(A)‖₂`, the operator norm from the tangent norm induced on `M_r` to the product Frobenius norm on the summand directions. The derivative must be taken **after** the individual normalizations. Replacing it by `κ(A)/‖A‖`, by the ordinary inverse-derivative condition number, or by a global scalar normalization changes the problem.

`Target` is the strict finite real expectation `∫_{M_r} κ_ang(A) dμ(A)<∞` for every admissible format and `r≥3`. The claim is not a format-uniform finite upper bound; no explicit constant is required. The average is with respect to the exact volume-Gaussian law above. An acceptable Lean boundary must concretely define the tensor rank-one variety, real smooth identifiable locus, induced volume, local inverse derivative and angular operator norm (or proved equivalent intrinsic formulations). Opaque `ConditionNumber` or arbitrary `μ` would not retain the target.
