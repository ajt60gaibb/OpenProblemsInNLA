# Location of the original runtime review

The five original files in this directory are retained byte-for-byte from the
independent review packet `PF03-runtime-referee2`. Its manifest authenticates
that packet, before this explanatory note was added.

The report and `audit_runtime.py` describe the original recovery workspace.
Their relative recovery-directory references and the local Forsythe checkout
are historical execution inputs, not a portable command for this published
directory. In particular, the previous review is now available at
[`../final-referee2/REVIEW.md`](../final-referee2/REVIEW.md), and the Linux
artifacts are in [`../../verification/linux-2026-09-19`](../../verification/linux-2026-09-19).
The original report, script, API observations and audit output have not been
rewritten to imply another execution after relocation.

For an independent fresh proof check, use the local build or the pinned Linux
bootstrap and verifier described in [the project README](../../README.md).
