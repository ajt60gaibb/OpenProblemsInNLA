# IE-21 Lean formalization scaffold

This directory records the approved Lean statement boundary and the supporting lemmas currently checked for IE-21. The full target is in Challenge.lean; Solution.lean is intentionally incomplete and does not import the challenge. This project is **not Lean verified**: see SPEC.md, the blocker notes, and the retained verification records for the exact scope and limitations.

Pinned toolchain and metadata are in `lean-toolchain`, `lakefile.toml`, and `formalization.yaml`. The independent review records are in `reviews/`.
