# Independent replay method

All 80 locked source modules (77 TR26 proofs and the three shared live/frozen modules) are compiled into my own initially empty `/private/tmp/nla-tr26-full-inventory-ecc597/out` directory. No author proof object is imported. The exact launched first-stage driver is preserved as `initial-driver.py`; every compiler output and source input is retained under `replay/`.

While reviewing that driver I detected a reviewer-only consumer assembly error: concatenating the author frozen audit before a second import header creates invalid late import commands. Candidate sources are unaffected. The corrected portable `reproduce.py` compiles the author exact frozen audit as its own separate module, followed by an independent consumer covering all public theorem/lemma declarations, including attached attributes. It also checks all three reference holes, three actual exact-typed custom-axiom counterfeits, and three definition-kind counterfeits.

After the first-stage 80 source compilations finish, the continuation may copy only these same independently owned objects, checking every original source against immutable ecc597 and binding its object and raw compiler-log hashes. `--reuse-own-build`, `--reuse-own-output` and `--reuse-own-driver` make that explicit in the accepted receipt. No repeated source compiler command is claimed for a copied object. The default invocation without those flags recompiles all 80 sources from scratch before the six final audit/control commands. Both stages use official Lean4.33.1 and the exact ten pinned clean dependencies, checked again after the continuation. This is source replay on macOS, not a Linux, exporter, raw-kernel or CI receipt.
