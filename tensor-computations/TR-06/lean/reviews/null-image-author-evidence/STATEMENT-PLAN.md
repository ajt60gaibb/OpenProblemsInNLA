# Pre-proof null-image boundary

General finite-dimensional real inner product spaces E,F; arbitrary set s, with no measurability or injectivity requirement. A global C1 map f and volume(s)=0 imply normalized source-dimensional Hausdorff measure of f(s) is zero. Source dimension, not target dimension, indexes the image measure. No local tensor-chart conclusions are built into the assumptions.

Proof plan: C1 gives a finite Lipschitz constant on each compact convex closed ball centered at zero. Each s∩closedBall has zero volume, hence zero normalized source-dimensional Hausdorff measure by the Euclidean normalization theorem. Apply the previously reviewed Lipschitz image bound. Countable closed-ball exhaustion and measure-zero countable unions give the result, including dimension zero. This is only a null-image transfer lemma; a nonzero polynomial pullback in actual dimension-k Segre parameters remains necessary for tensor exceptional-set nullity.
