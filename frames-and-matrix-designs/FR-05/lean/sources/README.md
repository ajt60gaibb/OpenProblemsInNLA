# Frozen informal source

This directory retains the source proof used by the FR-05 formalisation.
The public canonical source is Zhangsong Li, *Resolution of Vinzant's
Conjecture on Phase Retrieval Injectivity*, dated 13 September 2026,
<https://zhangsong-li.github.io/injectivity_phase_retrieval.pdf>.

`injectivity_phase_retrieval.pdf` is a retrieval snapshot, not a claim of
source-author endorsement or independent review. Its SHA-256 and the retrieval
timestamp are recorded after a successful download in `SOURCE_FREEZE.md`.
