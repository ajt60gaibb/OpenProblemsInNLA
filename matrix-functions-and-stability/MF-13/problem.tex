\hypertarget{problem-statement}{%
\subsection{Problem statement}\label{problem-statement}}

For each real matrix \(A\in\mathbb R^{6\times6}\), define
\(L_A(X)=AX+XA^T\). Write
\(\|X\|_F=(\mathop{\mathrm{tr}}\nolimits(X^TX))^{1/2}\). Is it true that

\[\max_{X\in\mathbb R^{6\times6},\ \|X\|_F=1}\|L_A(X)\|_F
=
\max_{X=X^T,\ \|X\|_F=1}\|L_A(X)\|_F
\qquad\text{for every }A\in\mathbb R^{6\times6}?\]

This concerns the \textbf{largest} singular value of the Lyapunov
operator, with no stability assumption on \(A\).

\hypertarget{why-it-matters}{%
\subsection{Why it matters}\label{why-it-matters}}

Restricting a norm calculation to symmetric matrices substantially
reduces the associated singular-value problem. The conjecture asks when
that reduction retains the exact operator norm, an issue relevant to
matrix-equation norm estimation.

\subsection{Lean proof and verification

The
\href{https://github.com/jinshanmu/SymmetricMaximizer/tree/9a1cedcf3bec473a322b45d770bedeac7050dbb9/Lean}{published

\href{https://github.com/leanprover-community/mathlib4/tree/fc4f59e577feb1a4956671bc04ac18aaaf8cd842}{mathlib

At dimension six,
\textit{SymmetricMaximizer.symmetric\_maximizers\_all\_orders} gives a
symmetric Frobenius-unit matrix that attains the whole operator norm for
every real coefficient matrix.

The
\href{https://github.com/ajt60gaibb/OpenProblemsInNLA/blob/main/references/jin-mf13-2026-11-21/verification/MF13Check.lean}{exact
target check} uses real \(6\times6\) matrices, ordinary transpose, and
the operator \(X\mapsto AX+XA^T\). The declaration
\textit{MF13Verification.frobenius\_norm\_eq\_sqrt\_trace} identifies
the scoped matrix norm with the trace formula above.
\textit{MF13Verification.common\_maximum} establishes attainment and a
common greatest value on both unit domains.
\textit{MF13Verification.equal\_maxima} then states the equality as an
equality of suprema. The coefficient matrix is unrestricted.
