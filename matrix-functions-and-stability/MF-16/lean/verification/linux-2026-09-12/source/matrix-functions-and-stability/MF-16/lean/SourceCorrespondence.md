# MF-16 source correspondence and exact scope

This is a statement-first formalization of the complete retained [MF-16 canonical target](https://github.com/ajt60gaibb/OpenProblemsInNLA/blob/5830ed4fb06da0659414a3deb2a40ad327aca052/matrix-functions-and-stability/MF-16/README.md), at the fixed original source snapshot `5830ed4fb06da0659414a3deb2a40ad327aca052`. No canonical target or source file is modified.

The mathematical solution belongs to **Matthew J. Colbrook**, [*Nonuniqueness of a symmetric word equation in two-by-two positive definite matrices*](https://github.com/ajt60gaibb/OpenProblemsInNLA/blob/5830ed4fb06da0659414a3deb2a40ad327aca052/references/colbrook-matrix-functions-2026-09-11/manuscripts/MF-16.tex). Its complete independent informal review and both complete interval implementations were read. Formalization credit is **George Stepaniants, Department of Computing and Mathematical Sciences, California Institute of Technology, Pasadena, California, USA**, with AI assistance. Source files retain their existing authorship, references and licenses; new code's Apache license does not reassign the manuscript.

| Formal contract | Actual source correspondence and necessary proof |
| --- | --- |
| `WordUniquenessConjecture` | Complete canonical Problem statement: every finite ordinary two-letter palindrome with X occurring, all complex Hermitian PD B,P of order two, exactly one complex Hermitian PD X. Written-order `List.prod`; genuine `Matrix.PosDef`; no real-only or fixed-word narrowing. |
| `word_semantics` | Source Theorem1's `XBX^12BX`. Actual list has16letters,14X,2B, equals its reverse, and evaluates to the natural matrix-power product for both real and complex matrices. |
| `source_data` | Exact unchanged B,X0,P in Theorem1, actual word equality, genuine PD after complexification and true determinants1,3,3^14. |
| `twelfth_power_reduction` | Source independent rational verifier uses the Cayley–Hamilton recurrence on det(S)=3. The formalization proves the explicit twelfth-power Horner polynomial identity for the genuine matrix, with no assumed recurrence. |
| `polynomial_word_equivalence` | Source Theorem4's determinant/two-entry recovery idea, adapted to three independent polynomial variables. The actual Expr zero is equivalent to det(S)=3 plus the first two actual word entries; every evaluation/coercion/CH bridge remains a proof obligation. |
| `krawczyk_certificate` | New exact rational certificate for a larger3Dbox near the source's second additional root. All actual checker conditions, detC, box radius and interval-matrix contraction bound are explicit obligations. This data is not falsely attributed to the source's printed2Dboxes. |
| `certified_root` | Actual existence and uniqueness of a real polynomial-system zero inside the single box, using the pinned LeanCert theorem's derived Jacobian/fixed-point argument. A Python or machine-evaluation diagnostic does not prove this statement. |
| `root_to_matrix` | Source Theorem4's full-matrix recovery from determinant and two entries, now with explicit box→x>3, complex PD, symmetry, determinant multiplication, remaining-entry equality and distinctness obligations. |
| `counterexample` | The complete negative answer of source Theorem1, established by two actual solutions rather than the degree theorem. |
| `not_wordUniquenessConjecture` | Unconditional negation of the complete original canonical assertion. |

The source's Theorem4 certifies **three** real solutions using two radius10^-40,110-decimal two-variable boxes. This formalization deliberately needs **one additional** root distinct from the unchanged X0. It uses a radius10^-7 three-variable box, ten-decimal rational center and preconditioner, and det(S)=3 as a polynomial equation. It does **not** use the unsupported inverse expression `(3+y²)/x` in LeanCert AD. The chosen root is the source's second additional root near `(3.49434510663918,-0.33048510081377)`; the third coordinate is recovered independently before rounding. The exact adapted data is in `NUMERICAL_TARGETS.md`, `Definitions.lean` and `selected-certificate.json`.

No negative Jacobian/Armstrong–Hillar degree theorem, exponent threshold, all-three-root count, minimality or priority assertion is exported or assumed. Omitting these stronger ancillary source claims does not weaken the full original universal uniqueness target's negation.
