# Source record

The following primary sources were read through public webpages in this round. No GitHub connector was used. They identify the target, reporting conventions, and adjacent literature; the new mathematical arguments are proved in full in the report.

1. OpenProblemsInNLA, canonical TR-09 statement. It retains arbitrary deterministic base factors and expressly distinguishes optimization from algebraic tensor recovery. https://raw.githubusercontent.com/ajt60gaibb/OpenProblemsInNLA/main/tensor-computations/TR-09/README.md
2. Dionysis Arvanitakis, Vaidehi Srinivas, and Aravindan Vijayaraghavan, *Open Problem: How much overparametrization is needed for ALS in tensor decomposition?* PMLR 336, 7105–7110, 2026. https://proceedings.mlr.press/v336/arvanitakis26a.html
3. Jiawang Nie and Ke Ye, *Hankel Tensor Decompositions and Ranks*. SIAM Journal on Matrix Analysis and Applications 40(2), 486–516, 2019. DOI 10.1137/18M1168285. The publisher's abstract and metadata were read; the paper is background for Hankel/Vandermonde methods, not a theorem imported without proof. https://epubs.siam.org/doi/10.1137/18M1168285
4. Jianze Li, Konstantin Usevich, and Pierre Comon, *Globally convergent Jacobi-type algorithms for simultaneous orthogonal symmetric tensor diagonalization*, arXiv:1702.03750v2, 2017. The Introduction explicitly distinguishes sequence convergence to a stationary point from convergence to a global maximum. https://arxiv.org/html/1702.03750v2
5. OpenProblemsInNLA, README and CONTRIBUTING. Status and evidence conventions. https://raw.githubusercontent.com/ajt60gaibb/OpenProblemsInNLA/main/README.md and https://raw.githubusercontent.com/ajt60gaibb/OpenProblemsInNLA/main/CONTRIBUTING.md
6. Previous fourth-round working report, supplied in this conversation and preserved in `prior/TR09_fourth_round_report.md`. It is not an independently reviewed publication.
