# [AA-01] Proposed signed-gap decision criterion and full proof for review

### Affected entry

AA-01, deciding accurate evaluability of real polynomials, in the
arithmetic-and-complexity section.

https://github.com/ajt60gaibb/OpenProblemsInNLA/tree/main/arithmetic-and-complexity/AA-01

### Proposed result

The attached manuscript, **A signed-gap decision criterion for accurate polynomial
evaluation**, proposes a complete decision procedure for the entry's finite-tree,
constant-free, independent-error model on all of real space. It is not a
finite-degree or finite-dimension verification.

For every signed ordering of the input magnitudes, substitute

\[
 x_{\pi(i)}=\sigma_i(y_1+\cdots+y_i),\qquad y_i\ge0,
\]

and collect `q(y)=p(x(y))=sum_alpha c_alpha y^alpha`. Write
`q#(y)=sum_alpha |c_alpha| y^alpha`.

The proposed characterization is:

\[
 p\text{ has an accurate finite computation tree}
 \quad\Longleftrightarrow\quad
 \text{for every chart, }\exists C\ge1\ \forall y\ge0:
 q^{\#}(y)\le C|q(y)|.
\]

There are finitely many charts, and each condition is a first-order sentence over
the reals with integer coefficients. Real quantifier elimination therefore gives
an always-halting decision procedure. When the conditions hold, a canonical
constant-free evaluator and a precision bound can be constructed.

### Evidence and proof structure

Theorem 1.1 in the manuscript is the main statement. Sections 2–4 supply the full
argument. Sufficiency evaluates the gap expansion directly. Necessity uses two
new lemmas proposed in the note:

1. Every fixed input admits a legal execution whose distinct rounded roots are
   uniformly separated, up to sign, from all earlier roots, with zero–zero pairs
   excepted.
2. After a small multiplicative perturbation of the signed gaps, the computation
   can be replayed along the same path, with every rounded value held fixed by
   legal changes to the occurrence errors. Raw comparisons, mixed comparisons,
   equality cases, exact signed aliases, and stored-value reuse are covered.

Uniform accuracy then bounds the target polynomial on a fixed multiplicative
neighborhood of each gap point. Tensor-product polynomial interpolation bounds
all gap coefficients and gives the necessary majorant condition.

The package also contains exact-rational replay diagnostics, symbolic example
certificates, a legal-instruction compiler, and zero-error/error-bound checks.
These computations are supporting diagnostics, **not a formal verification of
the general theorem**. The external Wolfram Language quantifier-elimination
backend generated by the code was not executed in the recorded environment.

### Model and scope

The statement covers arbitrary integer polynomials with `p(0)=0` and `n>=1`,
nonhomogeneous polynomials, a fixed finite computation tree, exact real inputs,
rounded binary `+,-,*`, exact negation, exact comparisons of available values,
branching, and stored-value reuse. Different arithmetic occurrences have
independent arbitrary errors. Comparison outcomes are control flow, not numeric
constant input nodes.

It does not claim a result for added constants, arbitrary exact polynomial
predicates, fused multiply-add, extra exact scalings, division, unbounded adaptive
loops, restricted domains, or the different correctly-rounded IEEE model.
