# SP-11 — The delta conjecture for minimum symmetric rank

**Classification:** literature-dependent affirmative resolution note; eligibility audit incomplete.

## Statement and notation

For a finite simple graph G with n >= 1 vertices, let S(G) be the real symmetric n-by-n matrices whose off-diagonal nonzero entries occur exactly at the edges of G. Diagonal entries are unrestricted. The target is

    mr(G) := min { rank(A) : A in S(G) } <= n - delta(G),

where delta(G) is the minimum vertex degree. This is the formulation in the repository's SP-11 entry [R11].

Define nu(G) to be the maximum nullity among positive-semidefinite members A of S(G) satisfying the strong Arnold property: the only symmetric X with AX = 0, A ∘ X = 0, and I ∘ X = 0 is X = 0.

## External theorem

Hall [H], Corollary 3.22, states that nu(G) >= delta(G) for every finite simple graph. The underlying main result is Theorem 3.20. This note takes that theorem as an external input; it does not independently establish it.

## Deduction

Choose a positive-semidefinite SAP matrix A in S(G) with nullity at least delta(G), as provided by [H]. Forgetting the additional positive-semidefiniteness and SAP requirements still leaves A in S(G). Rank-nullity gives

    mr(G) <= rank(A) = n - nullity(A) <= n - delta(G).

Thus Hall's stated theorem implies exactly the affirmative answer requested in SP-11. No assumption of connectedness, no prescribed values for nonzero edge entries, and no additional restriction on the diagonal are introduced. When delta(G) = 0, the requested bound also holds trivially.

## Attribution and scope

The substantive all-graph existence theorem belongs to Hall. In fact, Hall's Corollary 3.24 explicitly states the ordinary Delta Conjecture as a consequence. This note is a mapping of an existing literature result to a repository entry, not a claim to a new solution. The correctness of the general conclusion rests on the cited theorem.
