# Original reviewed manuscript snapshots

These four Markdown files preserve the supplied drafts byte for byte. Their full-file SHA-256 hashes appear in the independent review reports (UTF-8 with LF line endings). Draft status and provenance statements here describe the original submission, not the current catalog status. The authored, current manuscripts are each entry's `solution.md`; the parent submission record links them and explains every metadata, status and bibliographic update. All mathematical sections were checked unchanged.
