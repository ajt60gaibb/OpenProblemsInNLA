For each \(n\ge2\), partition \(\mathbb Z_n\smallsetminus\{0\}\) into
classes \(\{s,-s\}\) (a singleton when \(s=-s\)). Select each class
independently with probability \(1/2\) and let \(S\) be their union.
Form the simple undirected graph \(G_n\) on \(\mathbb Z_n\) with
\(\{i,j\}\) an edge exactly when \(i-j\in S\).

For any graph on \(n\) vertices put

\[\vartheta(G)=\max\Bigl\{\sum_{i,j}X_{ij}:X\in\mathbb R^{n\times n},\ X=X^T\succeq0,\ \mathop{\mathrm{tr}}\nolimits X=1,\ X_{ij}=0\text{ if }\{i,j\}\in E(G)\Bigr\}.\]

\textbf{Conjecture.}
\(\displaystyle\lim_{n\to\infty}\mathbb E\vartheta(G_n)/\sqrt n=1\).

Cyclic symmetry reduces this semidefinite program to a linear program
involving the discrete Fourier matrix, connecting its typical optimum
with structured sampling.

\hypertarget{scope-and-prior-work-2026-11-22}{%
\subsection{Scope and prior work ---
2026-11-22}\label{scope-and-prior-work-2026-11-22}}

Chen et al., Theorem 1.1, establish the sharp expectation limit through
all odd orders, including composite orders. Jin's Section 3 treats the
residue classes over every cyclic group, with one fair bit for the
singleton antipodal class at even orders. The proof combines the
complement lower bound with a Fourier smoothing upper bound. Leaf-sum
counts and tree fields give a trial vector, and the Fourier sign-sum
tail controls the exceptional events in the expectation. The result
covers the full displayed limit.
